# toktier

toktier is a correctness-first tokenization system for stateful LLM serving.
Its public contracts define exact token-ID behavior, verified artifacts,
session persistence, and certified routing across CPU and GPU backends.

The frozen interfaces and invariants are documented in [`docs/contracts/`](docs/contracts/).
