# TokTier 0.1.1

TokTier 0.1.1 is a compatible routing and long-session repair release. Public
APIs, routing policies, the 64 KiB GPU crossover, certified artifact roster,
store format v1, and exact-ID contract are unchanged.

## Changes

- Added the pure-Rust `toktier-routing-core` crate. UTF-8 byte-threshold
  selection and the no-hit added-token necessary-condition gate now execute in
  one private native call without allocating complete Python `bytes` copies.
- Moved the certified O/S/L/N/M BPE seal predicate into the native store
  adapter. The predicate retains the CR/LF and apostrophe carve-outs, rejects
  byte-fallback mid-character cuts, and observes the longest-added-literal end
  guard.
- Retained a family-sized repair tail when sealing. A multi-megabyte session
  can therefore continue through corrected-Gigatoken repair instead of
  crossing the 1 MiB hard cap and degrading to a full HF re-encode.
- Made the synthetic facade hardware-probe test accept the accurate
  `R_UNCERTIFIED_ARTIFACT` result on hosts where a real CUDA runtime and device
  are present.

## Validation

- Python suite: 667 passed, 17 skipped on the CPU release environment.
- Rust workspace: 46 tests passed, including the new route/prefilter/boundary
  crate.
- RTX 5090 (`sm_120`) GPU suite: 13/13 passed through the shipped prebuilt
  fatbin.
- A 4,000,000-character `qwen3_8b` session was seeded on the prebuilt GPU, then
  extended by 1,500 and 100,000 characters. Both appends used
  `gigatoken_repair`; the store recorded three native seals and zero hard-cap
  degradations; every returned ID stream matched a fresh HF `tokenizers`
  0.22.2 encode.
- On the same Intel Core Ultra 9 285K / RTX 5090 host, the routing-only 4 MB
  no-literal microprofile fell from 2.970 ms (the 0.1.0 allocation shape) to
  0.052 ms (57.5x). This is a control-plane measurement, not an end-to-end
  tokenization claim; see `docs/native-routing.md`.

## Install

```bash
pip install --upgrade toktier==0.1.1
pip install --upgrade "toktier[gpu]==0.1.1"
```

As with 0.1.0, the release artifact is one ABI3 Linux x86-64 wheel. No sdist is
published because rebuilding the certified vendored CPU binary during install
would produce a different artifact.
