# TokTier 0.2.6

**Status: in preparation.** This document is written as the 0.2.6 work
lands and is not a published release note yet. Numbers, evidence
references, and the release date below are filled in at the release cut.

TokTier 0.2.6 is a certification-scope release on the 0.2 line. Served
ids, the store format, the shipped fatbin, and the kernel ABI are
unchanged, and existing Python facade calls remain source-compatible.

Version axes moved by this release (see `docs/contracts/versioning.md`):
the package version (axis 1) moves to 0.2.6, and the six published
crates carry it together. The public API version, registry schema
version, store format version, kernel ABI version, and certification
suite version do not move.

## Upgrading

`pip install --upgrade toktier` for the Python package; nothing to do.

## Release-cut checklist

Items that are deliberately not final in this tree:

- `CITATION.cff`'s `date-released` and `RELEASE_DATE` in
  `tools/verify_release_identity.py` still carry the 0.2.5 date. They
  move together on the day of the cut.
- The README News entries carry `2026.08.TBD` until that day.
- The whole release certification battery runs on the cut tree. The
  0.2.5 evidence bindings in this tree are stale by construction: the
  version bump moves every recorded build identity.
