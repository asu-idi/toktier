# TokTier 0.2.8

Release notes for the 0.2.8 release. Sections are added by the work that
lands in it; this page opens with the coverage the release examined.

## Coverage examined in 0.2.8

### Examined and not certified: the Hy4-preview tokenizer

`tencent/Hy4-preview` ships a `tokenizer.json` of sha256 `ff67615de6e6`
(9,358,955 bytes) at revision `705d81ee5156`. It was examined on 2026-08-28
and is recorded in the support matrix under "Examined and not certified"
rather than counted as coverage. The repository is a preview publication, so
the pinned revision is part of what was read: a later revision that changes
these bytes is a different artifact.

Its `normalizer`, `pre_tokenizer`, `post_processor` and `decoder` sections
are byte-equal to the certified `hy3` artifact, which is a statement about
what a future campaign would cost rather than evidence about this artifact.
The model is a retrain: 120,000 vocabulary entries on both sides and 99,571
shared strings, of which only 132 carry the same id, with 119,744 merges
against 119,758. The capability fingerprint covers the model, so this is a
new pipeline capability, `pipeline.bdc79624a2c5a5ce`, composed with a new
added-token capability, `added-frontend.af450eb8cc1f3384`, and no reading
carries over from `hy3`.

The package therefore admits no accelerated route for it and reports
`R_UNCERTIFIED_ARTIFACT` where an accelerated backend is installed to be
assessed. `from_pretrained("tencent/Hy4-preview")` loads and returns the
reference engine's ids; ids stay exactly right, and acceleration is what is
withheld. There is no `hy4` family id in this release, so `load("hy4")`
reports `ARTIFACT_NOT_FOUND`.

Recording it is the point. A reader who looks for this repository finds what
was compared and what was concluded, instead of finding nothing.
